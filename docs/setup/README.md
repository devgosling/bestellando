## Voraussetzungen (Quick-Check)

Bevor du loslegst, musst du folgende Tools installiert haben:

| Tool | Version | Installation |
|------|---------|--------------|
| Node.js | ≥ 18 | https://nodejs.org |
| pnpm | 9.x | `npm install -g pnpm@9` |
| Git | aktuell | https://git-scm.com |
| Appwrite-Konto | — | https://cloud.appwrite.io |
| Stripe-Konto (Test-Modus) | — | https://dashboard.stripe.com |
| Google Cloud Konto | — | https://console.cloud.google.com |
