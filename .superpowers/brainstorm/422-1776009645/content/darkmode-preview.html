Implementation
Theme switching:
  • CSS custom properties on :root (light) and [data-theme="dark"]
  • Tailwind CSS dark: variant with class strategy
  • Respects prefers-color-scheme on first visit
  • Manual toggle in profile and header — persisted in localStorage
  • Existing @repo/contexts/ThemeProvider + @repo/hooks/useTheme already in place — extend them
  • Primary color shifts from #E63E11 → #FF6B3A in dark mode for WCAG contrast compliance
