Mobile navigation — how should users get around?

On small screens, navigation pattern matters a lot. This affects the whole app feel.

A

Bottom Tab Bar (App-like)

Fixed bottom bar with 4-5 icons: Home, Search, Orders, Cart, Profile. Always visible. Feels like a native app. Familiar to mobile users. Cart shows badge count. Active tab highlighted in brand orange.

B

Hamburger Menu + Floating Cart

Classic hamburger menu (☰) top-left with slide-out drawer for navigation. Floating cart button bottom-right with item count badge. More screen space for content but navigation is hidden behind a tap.

C

Top Header + Sticky Cart Bar

Compact top header with logo, search icon, and profile avatar. Main nav links in a scrollable horizontal row below header. Sticky mini cart bar at bottom appears when cart has items (shows total + "Zur Kasse" button). Desktop-to-mobile responsive approach.
